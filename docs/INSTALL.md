# Local installation — candidate 0.47

Build with the documented supported ROMs. Use only the resulting local
`packages/pmd-vita-fr-0.47.vpk`; keep it private. Title ID: PMDFR0001.
Close the game, make a verified independent copy of the entire
`ux0:/data/PMDFR0001/` directory, then install the VPK in VitaShell over the
existing bubble. Do not uninstall the application. Existing data paths/schema
are retained. Keep the previous VPK for rollback.

For acceptance testing, isolate original data and run on a copy as described
in HARDWARE-TEST.md. If installation is refused, stop rather than deleting data.
Triangle opens settings; the menu language can be changed to French.
The current build requires a homebrew-capable Vita with VitaShell. The exact
firmware/plugin configuration used for acceptance must be recorded; support for
all configurations is not implied.
